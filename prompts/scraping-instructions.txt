You are analyzing the website content for ChargeWizards, an EV charger installation company.

Your task is to extract and structure information about the practice and its providers into clean markdown summaries.

Please analyze the following website content and return a JSON object with this structure:

{
  "practiceOverview": "markdown content for practice overview",
  "providers": [
    {
      "name": "Provider Full Name",
      "slug": "provider-slug",
      "content": "markdown content for this provider"
    }
  ]
}

Guidelines:
- For practiceOverview: Create a markdown document with sections like:
  - "# Practice Name"
  - "## About" - Practice description and mission
  - "## Location" - Full address, city, state, zip code
  - "## Contact" - Phone number, email, website
  - "## Hours" - Office hours or note about scheduling
  - "## Parking" - Parking information and directions
  - "## Services" - List of services offered
- IMPORTANT: Extract the complete physical address, phone number, office hours, and parking details if present on the website
- For each provider: Create a markdown document with sections like:
 - Provider Name
 - Credentials
 - Insurance (CRITICAL - see detailed instructions below)
 - Approach
 - Contact
 - Fees
 - About
 - Specialties

- Use the provider's full name with credentials for the heading (e.g., "# Miri Arie, LMFT")
- Generate a kebab-case slug from the provider name (e.g., "miri-arie")
- Extract all relevant information including specialties, therapeutic approaches, contact details, credentials, insurance, contact, fees
- Format contact info as bullet points
- If information is unclear or missing, store that in a "questions.md" file under the 'practice' folder

=== CRITICAL: INSURANCE INFORMATION EXTRACTION ===

INSURANCE INFORMATION IS ABSOLUTELY ESSENTIAL FOR EVERY PROVIDER.

This is the MOST IMPORTANT piece of information to extract. The AI phone receptionist CANNOT answer caller questions about insurance without this data.

WHERE TO LOOK FOR INSURANCE INFORMATION:
- Provider bio sections (often near the end)
- Sections labeled "Insurance", "Accepted Insurance", "Insurance Accepted", "Insurance Plans"
- Sections labeled "Fees", "Payment", "Billing"
- Paragraphs mentioning insurance companies by name
- Bullet lists of insurance providers
- Anywhere in the provider's profile content

COMMON INSURANCE PROVIDER NAMES TO SEARCH FOR:
- Aetna
- Blue Cross Blue Shield (BCBS)
- Cigna
- UnitedHealthcare (UHC)
- Anthem
- Humana
- Kaiser Permanente
- Medicare
- Medicaid
- TriCare
- Optum
- Oscar Health
- Premera
- Regence

EXACT JSON STRUCTURE REQUIRED:
The "insurance" field in each provider object MUST be an array of strings:

CORRECT:
"insurance": ["Aetna", "Blue Cross Blue Shield", "Cigna"]

CORRECT (if no insurance found):
"insurance": []

INCORRECT (never use placeholder text):
"insurance": "Insurance information not provided"

INCORRECT (never use a string):
"insurance": "Aetna, Blue Cross"

EXTRACTION INSTRUCTIONS:
1. Search the ENTIRE provider section for insurance mentions
2. Look for insurance company names in paragraphs, lists, and headings
3. Extract each insurance provider name as a separate array element
4. If multiple insurance providers are mentioned, include ALL of them
5. If insurance information is in a sentence like "I accept Aetna and Blue Cross", extract both
6. If you see "most major insurance plans", try to find specific names mentioned elsewhere
7. Return an empty array [] ONLY if you have thoroughly searched and found NO insurance information

VERIFICATION CHECKLIST (complete before returning JSON):
[ ] Did I search for sections labeled "Insurance", "Fees", "Payment", or "Billing"?
[ ] Did I search the provider's bio/about section for insurance mentions?
[ ] Did I search for common insurance company names (Aetna, Blue Cross, Cigna, etc.)?
[ ] Did I check if insurance is mentioned in paragraphs or bullet lists?
[ ] Is my "insurance" field an array of strings (not a string or placeholder)?
[ ] If I found insurance information, did I include ALL providers mentioned?
