# Product Overview

AI-powered phone receptionist for Relational Therapy Collective (RTC), a therapy practice.

## Core Functionality
- Answers incoming phone calls with AI-powered voice interaction
- Greets callers and provides information about therapy services
- Uses speech-to-text to understand caller questions
- Generates natural, empathetic responses via AI
- Maintains conversation context throughout the call

## Key Components
- Twilio integration for phone system and speech recognition
- OpenRouter API for AI responses (GPT-4)
- Express server handling webhooks and call flow
- TwiML for voice interaction control

## Current Status
Working demo with basic conversational capabilities. Future enhancements include data integration, appointment booking, crisis detection, and tool calling for insurance/availability lookups.
