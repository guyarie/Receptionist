About This Page

This is an example page showing how the AI chat widget appears on your website. The chat button is in the bottom-right corner.

How to Add the Widget to Your Website

Add these two code snippets to your website's HTML, just before the closing </body> tag:

<!-- Configure the widget (optional) -->
<script>
  window.RTCChatConfig = {
    apiUrl: 'https://your-server-url.com',
    position: 'bottom-right',
    primaryColor: '#667eea',
    title: 'Chat with us'
  };
</script>

<!-- Include the widget script -->
<script src="https://your-server-url.com/chat-widget.js"></script>

Configuration Options

  • apiUrl: Your server URL (required in production)
  • position: 'bottom-right' or 'bottom-left'
  • primaryColor: Hex color code for the widget theme
  • title: Text shown in the widget header

Features

  • ✅ Floating chat button in corner
  • ✅ Expandable chat window
  • ✅ Same AI receptionist as phone system
  • ✅ Customizable colors and position
  • ✅ Mobile responsive
  • ✅ Easy to embed with 2 lines of code
