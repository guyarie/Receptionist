✅ Manual Test Checklist

    
    
      
  • 💬 Floating chat bubble appears in the bottom-right corner of this page.
    • 
      
  • 🖱️ Clicking the bubble opens the chat panel; clicking again (or ×) closes it.
    • 
      
  • 👋 A greeting message appears automatically when the panel first opens.
    • 
      
  • ✉️ Typing a message and pressing Send displays the user bubble and then an AI reply.
    • 
      
  • ⏳ A typing indicator (three animated dots) appears while waiting for the AI reply.
    • 
      
  • 🔄 Refreshing the page and reopening the widget shows the previous conversation.
    • 
      
  • 🆔 The same session ID is reused after a page refresh (check localStorage inspector above).
    • 
      
  • 📵 Disabling the network and sending a message shows a graceful error message.
    • 
      
  • 📱 The widget is usable on a narrow viewport (mobile simulation in DevTools).
    • 
      
  • ⌨️ Pressing Escape while the panel is open closes it.
