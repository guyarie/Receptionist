🤖 RTC Chat Widget - Public Test Page

ℹ️ Test Page
This page tests the chat widget from a public URL. The widget should appear in the bottom-right corner.
⚠️ CORS Notice
If the widget doesn't work, you may need to configure ALLOWED_ORIGIN in your server's .env file to allow this domain.

Instructions:

  1. Look for the chat button in the bottom-right corner
  2. Click it to open the chat window
  3. Try sending a message to test the AI receptionist
  4. Check browser console (F12) for any errors

What to Test:

  • Widget appears and is clickable
  • Chat window opens/closes properly
  • Messages send and receive responses
  • Conversation history is maintained
  • Widget is mobile-responsive
